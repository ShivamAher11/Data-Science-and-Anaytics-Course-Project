## Data

Raw and processed data files are **not included** in this repository due to GitHub's 100MB file size limit — some of the cleaned/aggregated CSVs generated by the pipeline exceed 1GB. Below is everything needed to reproduce the full dataset locally.

### Sources

**1. Airbnb — London (via Inside Airbnb)**
- Site: https://insideairbnb.com/get-the-data/
- Scroll to the **London** section and download:
  - `listings.csv` — one row per listing (price, room type, host info, review scores, location)
  - `calendar.csv` — daily price/availability per listing over a year (demand signal)
  - `reviews.csv` — individual guest reviews with text and dates (sentiment signal)
- These are refreshed periodically by Inside Airbnb, so exact row counts may differ slightly from the figures in `reports/Project_Status_Report.docx`, which reflect the snapshot used for this project.

**2. Booking.com — Europe (515K Hotel Reviews)**
- Kaggle: https://www.kaggle.com/datasets/jiashenliu/515k-hotel-reviews-data-in-europe
- Download `Hotel_Reviews.csv` — 515,738 reviews across 6 European cities (London, Paris, Amsterdam, Barcelona, Vienna, Milan)
- Requires a free Kaggle account to download
- This project uses **London rows only**, filtered explicitly by the cleaning script (`Hotel_Address` containing "London")

### Folder structure expected by the script

data/
├── raw/
│ ├── listings.csv
│ ├── calendar.csv
│ ├── reviews.csv
│ └── Hotel_Reviews.csv
└── processed/ (auto-generated, git-ignored)


### Reproducing the cleaned dataset

1. Create the folders above and place the 4 raw files inside `data/raw/`
2. Install dependencies (one time):
```bash
   pip install pandas numpy
```
3. Open `scripts/clean_and_align_full_script.ipynb` in Jupyter and choose **Run All**. Its configuration reads from `data/raw` and writes to `data/processed`.
4. Cleaned outputs will be generated in `data/processed/`:
   - `airbnb_listings_clean.csv`
   - `airbnb_calendar_clean.csv` / `airbnb_calendar_agg.csv`
   - `airbnb_reviews_clean.csv` / `airbnb_reviews_agg.csv`
   - `airbnb_master.csv` — listings + calendar + reviews joined, one row per listing
   - `booking_london_clean.csv` — Booking.com, London only
   - `comparison_schema.csv` — both platforms mapped to one shared comparison schema
   - `cleaning_report.txt` — full log of every cleaning step, row counts, and dropped/flagged records

### Known data limitations (documented, not hidden)
- **No price field in the Booking.com dataset** — cross-platform price comparison is only possible on the Airbnb side
- **No guest-capacity equivalent on Booking.com** — hotels don't map to "accommodates N guests" the way Airbnb listings do
- **Time-period mismatch** — Booking.com reviews are from 2015–2017; Airbnb data reflects the current Inside Airbnb scrape date, so the two are not perfectly time-aligned
- **Different data grains** — Airbnb is listing-level, Booking.com is review-level; the two datasets are stacked into a shared comparison schema rather than row-merged

Full details on every cleaning step and the reasoning behind each decision are in `reports/Project_Status_Report.docx`.

### Feature engineering

After generating the cleaned outputs, open `scripts/feature_engineering.ipynb` in Jupyter and choose **Run All**. It reads `data/processed/airbnb_master.csv` and writes `data/processed/airbnb_features.csv`. Definitions, business reasons, cutoffs, modeling leakage controls, and limitations are documented in [`reports/feature_engineering.md`](reports/feature_engineering.md).

### Statistical analysis

After feature engineering, open `scripts/statistical_analysis.ipynb` in Jupyter and choose **Run All**. It compares rating distributions by room type, host portfolio size, local price position, and neighbourhood, with adjusted tests, effect sizes, confidence intervals, and subgroup rating coverage. Methods, results, interpretation, and limitations are in [`reports/statistical_analysis.md`](reports/statistical_analysis.md); machine-readable tables are generated under `data/processed/statistics/`.

### Business insights and recommendations

Open `scripts/business_insights.ipynb` in Jupyter and choose **Run All** to summarize rating sub-scores by host portfolio segment and regenerate evidence-based operational recommendations. The methods, observed gaps, proposed pilot, dashboard implications, and fairness/privacy cautions are in [`reports/business_insights_recommendations.md`](reports/business_insights_recommendations.md).

### Machine-learning model

Open `scripts/value_rating_model.ipynb` to train and compare mean/median baselines, Ridge regression, and Random Forest for Airbnb guest value ratings. Open `scripts/value_rating_low_value_classifier.ipynb` for the business-aligned classification experiment. Run each notebook's cells in order. Both require `scikit-learn` and `joblib` in addition to pandas and numpy. They use host-held-out evaluation and write local outputs under the git-ignored `data/processed/modeling/` folder. The feature rationale, evaluation results, subgroup checks, interpretation, and limitations are in [`reports/value_rating_model.md`](reports/value_rating_model.md).

Install the additional model dependencies if needed:
```bash
pip install scikit-learn joblib
```

### Jupyter notebooks

The project code is provided as Jupyter notebooks in `scripts/`. The original `clean_and_align_full.ipynb` and `eda_visualization.ipynb` are preserved. `clean_and_align_full_script.ipynb` is the notebook version of the cleaning pipeline. Open the relevant notebook, review its setup and data-path cells, then choose **Run All**.
